# Screenshots

Empty until captured. Follow `../SCREENSHOT_CHECKLIST.md` — it gives the exact
filename and a ready-to-paste caption for each shot.

## Naming

`NN_area_what.png` — two-digit number first so they sort into the order they
should be read in.

## Rules for this folder

- **Real captures only.** Everything in here must be an actual screen capture
  of Rhino or Grasshopper on this machine, or a Grasshopper animation frame.
- **The diagrams are not screenshots.** `../diagram_*.svg` are drawings. They
  live one folder up on purpose, so the two can never be confused when
  someone forwards a folder.
- If a shot shows something that is not working yet, keep it and label it. A
  progress record with a failure in it is worth more than one without.
